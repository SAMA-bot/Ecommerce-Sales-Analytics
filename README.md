# 📊 Sales Performance Dashboard

An interactive **Sales Analysis Dashboard** built in **Microsoft Power
BI** using the Superstore sales dataset.

The dashboard provides a clean, high-level view of sales performance and
lets users explore results using interactive filters.

## 🎯 Project Overview

The project analyzes sales performance across:

-   Product categories
-   Customer segments
-   Geographic regions
-   Yearly sales trends
-   Overall sales and order performance

The final dashboard presents key metrics and comparisons in a compact,
business-friendly layout.

## 🛠️ Tools Used

-   **Microsoft Power BI Desktop**
-   **Superstore Sales Dataset**
-   Power BI cards, charts, slicers, formatting, and interactive
    filtering

## 📌 Dashboard Features

### KPI Cards

  KPI                              Value
  ------------------------- ------------
  Total Sales                  **2.26M**
  Total Orders                **4.922K**
  Average Sales per Order     **459.48**

### Interactive Filters

The dashboard includes dropdown slicers for:

-   **Category**
-   **Region**
-   **Year**

The visuals update dynamically when filters are applied.

### Visualizations

1.  **Sales by Category** - compares Technology, Furniture, and Office
    Supplies.
2.  **Sales Over Time** - shows annual sales from 2015 to 2018.
3.  **Sales by Region** - compares West, East, Central, and South.
4.  **Sales by Segment** - compares Consumer, Corporate, and Home
    Office.

## 📈 Key Insights

-   **Technology** has the highest category sales at approximately
    **0.83M**.
-   **Furniture** follows at approximately **0.73M**.
-   **Office Supplies** records approximately **0.71M**.
-   Sales dip slightly in **2016**, followed by strong growth in
    **2017** and **2018**.
-   **West** is the highest-performing region at approximately
    **0.71M**, followed by **East** at **0.67M**.
-   **Consumer** is the strongest customer segment at approximately
    **1.15M**.
-   **Corporate** contributes approximately **0.69M**, while **Home
    Office** contributes approximately **0.42M**.

## 🎨 Dashboard Design

The dashboard uses a simple business-focused design:

-   Light blue background
-   White rounded visual containers
-   Blue primary chart elements
-   Large KPI values
-   Consistent spacing and alignment
-   Dropdown slicers below the KPI section
-   Horizontal bar charts for regional and segment comparisons

## 🚀 How to Use

1.  Download the `.pbix` file.
2.  Open it with **Microsoft Power BI Desktop**.
3.  Use the **Category**, **Region**, and **Year** dropdown slicers.
4.  Explore how the KPI cards and charts respond to the selected
    filters.
